## Problem
Local artisans in Lahore struggle to reach buyers beyond their immediate neighbourhood, while buyers looking for authentic handmade goods have no easy way to discover and trust local sellers.

## Solution
Artisan Connect is a web marketplace where artisans list handmade products with their story, buyers browse by category and area, chat with an AI shopkeeper for guidance, and search by voice — all in English or Urdu.

## Features
- Browse by category (pottery, textiles, khussa, woodwork, food, services) and Lahore area
- Search with filters (price, area) + voice search
- Product pages with artisan stories and reviews
- Cart + guest checkout (Cash on Delivery)
- AI chatbot shopkeeper for buyer questions
- Custom order requests
- Seller/artisan shop profiles
- WhatsApp "chat with seller" integration
- Full Urdu/English bilingual interface
- Mobile-responsive design

## Tech Stack
- HTML, CSS, JavaScript (vanilla, no framework)
- Browser Web Speech API for voice search
- LocalStorage for cart and reviews
